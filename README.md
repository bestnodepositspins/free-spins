# Free Spins No Deposit – Jekyll Site

## Setup (30 minutes)

1. **GitHub nalog** → github.com → Sign up (besplatno)
2. **New repository** → `+` → New repository → Name: `free-spins` → Public → Create
3. **Upload fajlova** → `Add file → Upload files` → prevuci sve fajlove iz ovog zip-a
4. **Otvori `_config.yml`** → promeni `yourusername` na svoje GitHub korisničko ime
5. **GitHub Pages** → Settings → Pages → Source: **GitHub Actions** → Save
6. **Čekaj 2-3 min** → Actions tab → zeleno ✅ = sajt je live
